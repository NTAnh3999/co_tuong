These are the first real rows for the `Lesson` table T6.1 built (previously only a test fixture existed under `packages/content/src/__fixtures__/`, and `packages/content/data/lessons/` is empty).

## Read first

- `packages/content/src/schema.ts`'s `lessonSchema` — the EXACT shape every file must match: `slug` (unique, kebab-case, ASCII — e.g. `di-quan-tuong`, not Vietnamese diacritics in the slug itself), `title` (Vietnamese, can have diacritics), `level: 'beginner' | 'intermediate' | 'advanced'`, `contentVersion` (defaults to 1, you can omit it), `steps: [{ fen, caption, highlightSquares }]` (at least 1 step; `highlightSquares` is an array of square strings like `"a3"`, defaults to `[]` if omitted).
- `packages/content/src/__fixtures__/valid/lessons/fixture-lesson.json` — a minimal example of the exact JSON shape (not real content, just the shape).
- `packages/content/src/validate-content.ts`'s `validateLesson` — the ONLY thing it checks per step is that `fen` parses via `@xq/xiangqi-core`'s `fromFen`. It does NOT check that consecutive steps are connected by a legal move — each step's FEN is an independent board state you're free to construct by hand for teaching purposes (e.g. "here's what the board looks like after this tactic," without needing the exact move sequence that produced it). But every `fen` string itself MUST be a real, valid Xiangqi FEN per ADR-018's convention (files a-i, ranks 0-9, Red's back rank = rank 0) — don't invent an unparseable string.
- `docs/adr/ADR-018-coordinates-fen-uci.md` — the coordinate/FEN convention your FENs must follow.
- AGENTS.md's convention: lesson content is user-facing, so it's written in Vietnamese (titles, captions). Code/filenames stay in English/ASCII.

## Content to write

~10 lesson files (you choose exact topics/count within "~10", but cover a spread across all three levels — don't make them all beginner). Suggested topics, adjust freely for correctness and teaching clarity:

**Beginner (level: "beginner")**
1. Cách các quân di chuyển: Tướng (General) và Sĩ (Advisor) — palace-bound movement, diagonal-only advisor moves.
2. Cách các quân di chuyển: Xe (Chariot) và Pháo (Cannon) — straight-line movement, cannon's screen-capture rule.
3. Cách các quân di chuyển: Mã (Horse) và Tượng (Elephant) — the horse's L-shape with its blocking "leg," the elephant's river/eye restrictions.
4. Luật Tốt qua sông (soldier river-crossing rule) and basic pawn structure.

**Intermediate (level: "intermediate")**
5. Nguyên tắc khai cuộc cơ bản (basic opening principles — develop pieces, control the center file, don't move the general early).
6. Chiến thuật ghim quân / đổi quân hợp lý (basic tactics: pins, favorable exchanges).
7. Bảo vệ Tướng — cấu trúc phòng thủ cơ bản (basic king safety / palace defense structure).

**Advanced (level: "advanced")**
8. Nhận biết thế chiếu hết cơ bản (recognizing basic mating patterns — can reuse/adapt one of T6.2's verified mate-in-1/2 FENs from its test file as a teaching example, since those are already hand-verified true positions).
9. Luật chiếu đuổi liên tục không được tính (perpetual-chase-is-not-implemented note per ADR-017 — explain to a learner why repeated checks still just play out, there's no special "perpetual chase" draw rule in this app's ruleset) — frame this as "điều cần biết," not as a tactic to use.
10. Tổng kết: ba giai đoạn của một ván cờ (opening/middlegame/endgame overview).

Each lesson should have 2-5 `steps`, each with a real, valid FEN illustrating that step's point, and a short Vietnamese `caption` explaining what the learner should notice (use `highlightSquares` to point at the relevant squares where it helps).
